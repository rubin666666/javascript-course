🚀 Основи JavaScript

Інтерактивний курс для початківців

📋 Як користуватися курсом

🎯 Для початківців

  1. Відкрийте файл .js в текстовому редакторі
  2. Вивчіть код та коментарі
  3. Використовуйте JavaScript Тестер для експериментів
  4. Виконуйте завдання з файлів exercises/

🔧 Для досвідчених

  1. Завантажте всі файли локально
  2. Використовуйте Node.js: node 01-variables.js
  3. Або відкрийте tester.html для інтерактивного тестування
  4. Експериментуйте з кодом!
💡 Способи запуску коду:
• Відкрити JavaScript Тестер - найкращий спосіб для експериментів
• Скопіюйте код у консоль браузера (F12 → Console)
• Використайте онлайн редактор: CodePen або JSFiddle
• Запустіть через Node.js: node filename.js
💡 Корисні поради:
  • Відкрийте Developer Tools (F12) для додаткових виводів
  • Не поспішайте - краще добре зрозуміти одну тему
  • Експериментуйте - змінюйте значення змінних
  • Робіть нотатки під час навчання
